# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts the selling price of a used car using Machine Learning. It uses car details such as present price, kilometers driven, fuel type, transmission, ownership history, and car age.

## 🎯 Objectives
- Analyze and clean used car data.
- Perform Exploratory Data Analysis (EDA).
- Train and evaluate Machine Learning regression models.
- Build an interactive web application using Streamlit.

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## 📂 Project Files
- `Car_Price_Prediction.ipynb` — Data analysis and model training.
- `app.py` — Streamlit web application.
- `car_data.csv` — Dataset.
- `car_price_model.pkl` — Trained model.
- `requirements.txt` — Required Python libraries.

## ⚙️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd CodeAlpha_CarPricePrediction
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```

## 💡 Features
- User-friendly interface.
- Interactive car detail inputs.
- Machine Learning-based price prediction.
- Estimated price displayed in Pakistani Rupees.
